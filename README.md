# Matkalle — reitistä oikeaan lippuun

Karine Heinosen itsenäinen UX/UI-portfoliokonsepti. Staattinen verkkodemo GitHub Pagesiin.

## GitHub Pages

Repositorio on `karinehei/matkalle-figma`. Julkaistu osoite on [https://karinehei.github.io/matkalle-figma/](https://karinehei.github.io/matkalle-figma/).

Figma: https://www.figma.com/design/rmlkjd0VnSlmzUqju4ktjN/Matkalle-%E2%80%94-UX-UI-portfoliokonsepti?node-id=0-1

Paikallinen kokeilu: `py -m http.server 8000` ja [http://localhost:8000/](http://localhost:8000/). ES-moduulit eivät toimi `file://`-osoitteella.

Reitit, hinnat ja aikataulut ovat esimerkkejä. Maksaminen on simuloitu. Demo ei ole HSL:n palvelu.
